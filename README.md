# CSD-402 – Java for Programmers
Wade Eckert's Repository for CSD-402 - Java for Programmers

## Overview

This repository contains my coursework and programming assignments completed for **CSD-402: Java for Programmers** at **Bellevue University**.

The projects in this course focus on building a strong foundation in Java programming by applying object-oriented programming concepts, problem-solving techniques, and industry coding standards. Each module introduces new Java concepts that build upon previous assignments, resulting in progressively more complex applications.

## Running the Programs

Most assignments are standard Java console applications.

Compile:

```bash
javac ProgramName.java
```

Run:

```bash
java ProgramName
```

Some assignments include multiple Java files. In those cases, compile all required source files before running the application.
