# Java for Programmers

This repository contains my coursework for **Java for Programmers** at **Bellevue University**.

This course focused on developing applications using the Java programming language while building experience with fundamental programming concepts, object-oriented programming, collections, exception handling, inheritance, abstraction, and graphical user interfaces.

The coursework progressed from smaller programs demonstrating individual Java concepts to multi-class object-oriented applications and a final JavaFX graphical user interface.

---

## Module 10 – Abstract Division Application

Module 10 introduced abstract classes and expanded on inheritance and polymorphism through a multi-class Division application.

```text
module-10/
├── Division.java
├── Division.class
├── DomesticDivision.java
├── DomesticDivision.class
├── InternationalDivision.java
├── InternationalDivision.class
├── UseDivision.java
└── UseDivision.class
```

The application consists of an abstract `Division` superclass and two specialized subclasses:

* `DomesticDivision`
* `InternationalDivision`

`UseDivision` creates and works with the resulting objects.

This assignment demonstrated:

* Abstract classes
* Abstract methods
* Inheritance
* Superclasses and subclasses
* Constructors
* Method overriding
* Polymorphism
* Code reuse
* Multi-class application design

The assignment demonstrated how shared behavior and data can be defined in a parent class while specialized behavior is implemented by subclasses.

The course explored several data structures available through the Java Collections Framework.

These included:

* `ArrayList`
* `LinkedList`
* `HashMap`

Coursework examined how these collections store and organize information differently and how the appropriate collection depends on the requirements of an application.

## Exception Handling

Exception handling was studied as an important part of creating reliable Java applications.

The course explored how `try` and `catch` blocks can be used to detect and respond to runtime problems and how exceptions can be deliberately thrown when invalid conditions occur.

These concepts helped reinforce the importance of validating data and accounting for unexpected application states.
